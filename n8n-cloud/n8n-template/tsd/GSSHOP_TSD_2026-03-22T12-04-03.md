## 6.1 페이지뷰 트래킹 (Page View Tracking)

### 6.1.1 Analytics 변수 매핑
| 변수명 | 데이터 레이어 경로 | 설명 | SDR 매핑 |
|--------|--------------------|------|----------|
| prop1, eVar18 | web.webPageDetails.name | SPA 페이지 이름 | PageName |
| prop2 | web.webPageDetails.siteSection | 사이트 섹션 | SiteSection |
| prop3 | web.webPageDetails.pageType | 페이지 유형 | PageType |
| prop5 | web.platform | 웹/모바일/앱 구분 | Platform |
| prop6 | user.loginStatus | 로그인 상태 | LoginStatus |
| prop7, eVar14 | user.memberGrade, loyalty.grade | 회원 등급, 로열티 등급 | MemberGrade, LoyaltyGrade |
| prop17, eVar18 | site.spa.transitionType | SPA 페이지 전환 유형 | SPATransitionType |

### 6.1.2 배포 지침
| 단계 | 설명 |
|------|------|
| 1 | 데이터 레이어에 SPA 페이지 정보가 정확히 푸시되는지 확인 |
| 2 | Adobe Launch에서 Web SDK 확장 설치 및 구성 |
| 3 | 페이지뷰 발생 시 Launch Rule이 트리거되는지 확인 |

### 6.1.3 예시 Script
```js
window.adobeDataLayer.push({
  event: 'page-view',
  web: {
    webPageDetails: {
      name: '홈',
      siteSection: '메인',
      pageType: 'Landing',
      errorType: '',
      errorTypeRealtime: '',
    },
    platform: 'web'
  },
  user: {
    loginStatus: 'logged-in',
    memberGrade: 'VIP'
  },
  site: {
    spa: {
      transitionType: 'replace'
    }
  },
  loyalty: {
    grade: 'VIP'
  }
});
```

### 6.1.4 트래킹 설정 방법
| 설정 항목 | 값 |
|-----------|-----|
| 이벤트명 | page-view |
| 트리거 | SPA 라우트 변경, 최초 페이지 진입 |
| 데이터 전송 | Web SDK sendEvent (XDM) |

### 6.1.5 Adobe Launch Rule 생성
| Rule 이름 | 이벤트 | 조건 | 액션 |
|-----------|--------|------|------|
| PageView | page-view | 항상 | sendEvent (XDM 매핑)
